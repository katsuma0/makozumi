Writing the chip, safely:
  1. Open the tag link in a browser first and confirm it reads ✓ AUTHENTIC.
  2. In NFC Tools: Write → Add a record → URL → paste → Write.
  3. Lock the tag (Other → Lock tag, or set a password). An unlocked chip can be rewritten by anyone who can touch your product.
  4. Fix the chip to the item so that removing it destroys it.
  5. Record the serial number in your own list so duplicates are detectable.
